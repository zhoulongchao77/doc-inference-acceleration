# 风格提示词：稿纸网格 · 工程杂志风（Editorial Tech-Doc）

> 用法：写新博客/分享材料时，把下面整段提示词 + 你的内容大纲一起发给 AI，要求生成单文件 HTML。
> 也可以直接套用同目录的 `blog-template.html` 骨架手动填内容。

---

## 提示词正文（直接复制使用）

请用以下风格生成一份**单文件 HTML 技术长文**（所有 CSS/JS 内联，不依赖框架，仅允许 CDN 引入 Noto Sans SC / JetBrains Mono 字体与 KaTeX）：

### 整体气质
工程杂志风 / 稿纸网格风（editorial tech-doc）：像一份排版精良的技术白皮书，克制、信息密度高、有编号系统和图纸感。中文正文，术语保留英文原文。

### 视觉规范
- 背景：浅灰纸面 `#eceff3`，叠加 34px 固定细网格线（`#e7ecf2`），`background-attachment:fixed`
- 主文字藏青 `#16233a`，次级 `#3c4d66`，弱化 `#697a92`
- 强调色橙 `#e8590c`（软底 `#fdeee2`）；辅助语义色：青绿 `#0d9488`、蓝 `#2f6fb0`、金 `#b9832b`，各有对应 soft 底色
- 字体：标题/正文 Noto Sans SC（标题 900 字重）；编号、标签、数字、代码一律 JetBrains Mono
- 卡片：白底 + 1px 浅边 + 圆角 12–14px + 轻投影

### 页面结构（自上而下）
1. 顶部 3px 阅读进度条（橙→金渐变，随滚动增长）
2. 粘性顶栏：左侧品牌名（关键词用橙色），右侧章节锚点链接，毛玻璃背景
3. Hero 区：等宽字体 kicker 小标题（橙色、大写字距）、超大主标题（关键词 `<em>` 橙色）、一段 lead 导语、meta 胶囊行（主题/文献数等）、3–4 个彩色统计数字卡（藏青/青绿/橙/金底色，大数字 + 一句出处说明）
4. 左侧固定目录栏（宽屏显示，可拖拽调宽，宽度存 localStorage；由 JS 自动生成嵌套目录并滚动高亮当前节）
5. 正文分章节 `section#ch1..N`，每章节头 = 黑底编号徽章 `01` + 大标题 + 右侧等宽字体小注，下划 2px 墨线
6. 文末：参考文献（自动编号 `[1] [2]…`，含标题/出处/链接）、footer 署名、回到顶部按钮

### 内容组件（按需使用）
- `figure.fig` 图示卡：内嵌**手绘风 SVG 示意图**（圆角矩形节点 + 箭头 + 等宽字体标注，配色取自调色板），figcaption 以 `图N` 橙色编号开头；点击可全屏缩放（滚轮缩放/拖拽/ESC）
- `h3` 小节：JS 自动编号 `N.M`，前置橙色小方块
- `.callout` 提示框四色：`c-key`（橙，核心结论）/ `c-teal`（青绿，实践建议）/ `c-blue`（蓝，原理补充）/ `c-gold`（金，注意事项），带等宽字体小标题
- `.paper` 论文 chip：左色条 + 等宽编号 + 标题 + 一句话说明 + arXiv 链接
- `.tag` 标签：等宽字体小胶囊，五色
- 表格：藏青表头、斑马纹、hover 橙色软底，外层 `.tbl-scroll` 圆角卡片
- `ul.check` 勾选清单：青绿方框对勾
- `.formula-box` 公式卡 + KaTeX（`$...$` / `$$...$$`）
- `.grid2` 双栏栅格

### 写作要求
- 先给"全景地图"SVG 再逐站展开；每个技术点遵循「是什么 → 为什么慢/难 → 怎么优化 → 原始论文出处」
- 数据必须带出处（论文/实测），统计卡的数字要能在正文找到对应
- 示意图用原创 SVG，不引用外部图片
